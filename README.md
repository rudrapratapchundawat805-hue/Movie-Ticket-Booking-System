# Movie Ticket Booking System (MOVIEBOX)

A console-based Movie Ticket Booking System developed using Java as a first-semester academic team project.

## Overview

MOVIEBOX simulates a movie ticket booking process. Users can select a language, browse movies by genre, choose seats, order snacks and calculate their final bill.

## Features

- Language selection: Hindi and English.
- Movie genres: Action, Comedy and Horror.
- Movie and showtime selection.
- Interactive seat selection.
- Category-based ticket pricing.
- Snack ordering with individual items and combo meals.
- Automatic bill calculation with 5% GST.

## Technologies Used

- Java
- Object-Oriented Programming
- Arrays and 2D Arrays
- Constructors and Inheritance
- Scanner for user input

## Project Structure

- `Movie.java` – Main application flow and movie selection.
- `Action_Movie.java` – Action movie details.
- `Comedy_Movie.java` – Comedy movie details.
- `Horror_Movie.java` – Horror movie details.
- `SeatLayout.java` – Seat selection and ticket billing.
- `Meal.java` – Snack ordering and cost calculation.

## Limitations

- No user registration or login.
- No ticket cancellation or refund functionality.
- No persistent booking database.
- Limited cinema support.
- No online payment gateway.
